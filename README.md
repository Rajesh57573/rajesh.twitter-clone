# Twitter (X) Clone 🐦

A responsive Twitter/X clone built using **HTML and Tailwind CSS**, featuring a modern dark UI and a social media feed.

## ✨ Features
- Responsive design for mobile, tablet, and desktop.
- Navigation sidebar with icons.
- Post feed with images and videos.
- Like, comment, repost, bookmark, and share icons.
- Trending topics, news, and follow suggestions.
- Mobile-friendly layout using Tailwind CSS.

## 🛠️ Technologies Used
- HTML5
- Tailwind CSS
- Font Awesome

## 🚀 How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the Tailwind CSS build process if required.
4. Open `index.html` using Live Server.

## 📱 Responsive Design
Optimized for different screen sizes, including mobile devices, tablets, and desktops.
